Multi-List Task Manager

A simple, pastel-themed task management app that helps users organize their day with multiple to-do lists.

## Features

- **Create multiple lists** — Organize tasks into separate lists.
- **Edit lists** — Update list names, deadlines, and colors.
- **Delete lists** — Remove lists you no longer need.
- **Manage tasks** — Add and delete tasks within each list.
- **Track completion** — Mark tasks as complete and view them separately from active tasks.
- **Set deadlines** — Add deadlines to individual lists.
- **Customize colors** — Choose a color for each list.
- **Persistent storage** — Lists and tasks are saved in the browser using `localStorage`, so they remain available after refreshing the page.

## Built With

- HTML5
- CSS3
- JavaScript
- Browser localStorage
